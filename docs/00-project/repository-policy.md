# Политика репозитория

Источник правды: `nwcfollowthewhiterabbit/GL-website`, ветка `main`.

## Что хранится в Git

- код, схема, миграции и воспроизводимая конфигурация;
- роли, права, навигация и настройки процесса;
- deploy/backup/restore/validation после их реализации;
- требования, решения, проверки, релизы и пользовательская инструкция.

Live-fix в базе, панели управления или работающем runtime допустим только для
исследования. До завершения задачи он переносится в воспроизводимый артефакт.

## Изменение runtime

До мутации runtime обязательны repository checks, source/release commit и push.
Release-артефакт строится из точного commit и получает уникальную версию. Затем
создаётся и проверяется backup. Только после этого выполняются deploy,
migrate/setup и проверки.

## Git

- Перед работой проверять `git status`.
- Не перезаписывать чужие изменения.
- Делать небольшие содержательные commits.
- Не объявлять задачу завершённой при грязном дереве или неотправленном commit.
- Не хранить пароли, токены, приватные ключи и рабочие секреты.

## Проектные решения

Подтверждённое требование, открытый вопрос, ADR и исходная обратная связь имеют
разный статус и не подменяют друг друга. Неприменимый пункт отмечается
`Не применимо — <причина>`, а не удаляется молча.
