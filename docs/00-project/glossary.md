# Словарь

| Термин | Значение |
|---|---|
| Storefront | Публичная React/Vite часть сайта |
| Integration API | Node backend между storefront, ERPNext и Windcave |
| ERPNext | Источник catalog, customer и sales documents |
| Customer account | Защищенная зона клиента на `/account` |
| Order basket | Локальная корзина, отправляемая как quote/order request |
| Quotation | Draft коммерческое предложение в ERPNext |
| HPP | Hosted Payment Page Windcave |
| Payable document | ERPNext document, по которому backend создает HPP session |
| Website stack | Контейнеры web/api сайта, без ERP runtime |
| Testing | Неиндексируемое окружение `testing.greenleafpacific.com` |
| Evidence | Machine-readable результат runtime operation или validation |
| Foundation scaffold | Безопасный каркас, блокирующий ненастроенные runtime operations |
