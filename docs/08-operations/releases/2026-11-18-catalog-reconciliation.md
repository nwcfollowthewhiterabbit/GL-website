# Сверка прежнего каталога с ERP на тестовом сайте

В сборке `ea529c768a04f07cee184d0450f3eb68ad6e882c` тестовая витрина открывает 5034 артикулов с текущим предложением. Из 10 659 прежних кодов 426 ведут к продаже. Ранее их было 338. Полный справочник ERP содержит 6 969 совпадающих прежних кодов, включая позиции, для которых требуются описание, фото или уточнение условий.

Из 40 исключённых ранее артикулов два вновь доступны для запроса котировки. Для 20 сайт выводит общую цену за указанную единицу, для 18 доступно обращение в отдел продаж для уточнения условий. Подтверждена запись в изолированной ERP черновика с REW-LPC и WIN-WB-29S на 4 163,60 FJD. Тестовые записи очищены откатом транзакции. Для 248 позиций сверены характеристики, для 80 опубликованы соответствующие фотографии. Шесть других карточек восстановлены по изображениям и содержательным описаниям ERP.

Проверены исторические ссылки с совпадающими и изменившимися кодами, 81 архивная карточка без кода, варианты с общим артикулом и одинаковые/конфликтующие упаковки. Прежний код ALT-AT-F49FGD ведёт к ALT-AT-ST49FGA. Для 106 остальных сопоставлений сайт проверяет, существует ли предложение в исходной единице. Исторический ID сохраняется при отсутствии подходящего предложения.

Релиз протестирован на закрытом стенде и на `testing.greenleafpacific.com`. Активация тестовой версии завершена `2026-11-18T18:37:13.642967+00:00`. [Проверка исходников в CI](https://github.com/nwcfollowthewhiterabbit/GL-website/actions/runs/44369315257). Подробные материалы доступны в репозитории GreenLeaf Cloud, файл `docs/issues/website-catalog-reconciliation-20261118.md`. Перед активацией были сохранены контрольные копии обоих контуров. При откате возвращаются прежние образы API и web через утверждённую процедуру выпуска. Основной домен требует отдельного решения владельца.
