# Переходы со старого магазина

Сервер распознаёт прежние пути категорий и карточек, в том числе OpenCart
`index.php?route=product/product&product_id=…`. Соответствия в
`api/legacy-public-catalog.json` собраны из резервного снимка OpenCart
2026-11-17T13:34:25Z. Справочник включает ID, SKU, публичное название и
SEO-слова 10 665 включённых товаров, 502 включённых категорий и 35 производителей.
Для категорий указан ближайший раздел витрины. В этих данных нет заказов,
клиентов, паролей или цен. У сайта нет сетевой зависимости от старого OpenCart.

Известная карточка получает постоянный редирект на точный SKU. Выставленный
в ERP товар открывает текущую карточку. Если бывший товар сейчас отсутствует
в опубликованном каталоге, открывается страница с его прежним названием,
артикулом и контактом отдела продаж. Страница прежнего товара закрыта от
индексации. Неизвестным адресам возвращается HTTP 404. Для прежних заказов
покупателю показан порядок обращения в Green Leaf.

Sitemap включает страницы сайта и уникальные SKU из того же публичного
отбора ERP, что и витрина. Кеш идентификаторов действует пять минут. При
недоступности выборки сервер отвечает 503. Для публикации API и веб-образ
должны использовать совпадающие публичные настройки своего окружения.
Тестовый домен сохраняет noindex. Веб-сборка задаёт origin для sitemap
и канонических адресов. PDF-каталоги обслуживаются из прежних точек монтирования.
