# Runtime adapters

Не копируйте реализацию адаптера из другого проекта вслепую. Сначала определите
runtime, точные окружения, границы данных, необратимые операции, RPO/RTO и
владельца решения. Затем оформите ADR и тестируемую реализацию соответствующего
контракта.

Адаптер не принимает значения секретов через командную строку и не исполняет
произвольные строки shell. `--contract-probe` проверяет конфигурацию без мутаций.
