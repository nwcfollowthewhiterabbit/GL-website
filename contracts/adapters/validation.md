# Контракт validation

- `validate_instance`: точный target, версии, миграции, сервисы, роли,
  разрешения, конфигурация и health.
- `validate_domain`: состояния, инварианты, права, изоляция, идемпотентность,
  ошибки и cleanup с уникальным run ID.
- `validate_mvp_e2e`: golden path от предусловия до контролируемого результата и
  исправления.
- `validate_ui_e2e`: реальный браузер и роли, формы, quick entry, повтор,
  отчёты, ссылки и отрицательный доступ.

Production не используется как тестовая среда по умолчанию. Required-проверка со
статусом `skipped` не позволяет пройти release gate.
