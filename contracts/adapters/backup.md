# Контракт backup

Этот контракт обязателен для update и любой цели с существующим состоянием.
Первый deploy может не вызывать backup adapter только когда read-only проверки
доказали пустоту точной цели: deploy evidence содержит ссылку на эту проверку, а
backup отмечен `N/A — target proven empty`. Любое найденное или неясное
состояние блокирует first-deploy.

- Точно идентифицировать environment, instance и источник данных.
- Включить БД, restore-critical конфигурацию и пользовательские файлы либо явно
  описанные эквиваленты.
- Сохранить backup вне пересоздаваемого runtime.
- Рассчитать SHA-256 и размер каждого артефакта, проверить читаемость.
- Защитить материалы с секретами правами доступа и не печатать значения.
- Завершиться ошибкой при отсутствии любого обязательного компонента.
- Вернуть evidence с перечнем артефактов и результатом проверки.
